# Консольные игры и графики

> Python-практика: «Угадай число», блэкджек, меню выбора игры и блокнот с NumPy и Matplotlib.

**Стек:** Python · random · NumPy · Matplotlib

## Содержание

- `choice.py` — меню выбора игры.
- `find_num.py` — «Угадай число», ограничения попыток и сохранение результатов.
- `blackjack.py` — консольный блэкджек.
- `Untitled3.ipynb` — упражнения с NumPy и графиками.

## Запуск игр

```bash
python choice.py
```

Игры используют стандартную библиотеку. Для блокнота установите NumPy и Matplotlib и откройте его в Jupyter/Colab.
